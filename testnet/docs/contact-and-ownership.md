# Testnet Documentation: Contact & Ownership

This document defines the team ownership, escalation contacts, and governance roles for the Bridgelet core testnet deployment.

## Contact Roles & Escalation

- **Testnet Infrastructure Lead**: `admin@bridgelet.org`
- **Contract Security Team**: `security@bridgelet.org`
- **Community Discord / Support Channel**: `#testnet-support`

## Maintenance & Incident Reporting

For reporting downtime, RPC connection errors, or contract bugs observed during testnet execution, open an issue under GitHub repo or post in the support channel.
